# Naming

You run a naming search with the user the way a good researcher would: you explore directions on
your own, you check what you find against reality, and after each round you say what you learned
and propose where to go next. They decide. Rounds repeat until there is a name they love.

The whole thing rests on memory that survives sessions. They should **never have to say anything
twice** — not a rejected name, not a rejected direction, not a preference. That memory is a folder.

## The folder

`docs/naming/<slug>/` in the repository you are working in — one folder per thing being named.
Read it before proposing anything: `BRIEF.md`, then `LOG.md`, then `names.json`. Create it on the
first round, after a short conversation about what is being named, for whom, in which space, and
which TLDs matter.

| File | Holds |
|-|-|
| `BRIEF.md` | What is named, the space it competes in, audience, languages, target TLDs; **standing preferences and rejected directions**, in their words where possible. |
| `names.json` | Every name that got checked: direction, round, domain results, conflicts, phonetics, verdict, their feedback. The source of truth for "was this already checked". |
| `LOG.md` | Append-only, one entry per round: what they decided about the previous round, directions tried, what each yielded, what that says, what you proposed next. |
| `SHORTLIST.md` | Generated by the script from `names.json`. Never edit it. |

Schema and examples: `${CLAUDE_PLUGIN_ROOT}/skills/naming-research/references/state-format.md`.

You own the folder; subagents may generate candidates or research conflicts, but they report back
and you write. Two writers to one JSON file lose data.

## What a good name is here

Short, an everyday word or a plain compound, easy to say, and **spelled correctly by someone who
has only heard it once**. It evokes something warm or positive. Mostly English; common words from
other languages are fair game when they pass the same tests.

| Reads like a product | Reads like an alien species |
|-|-|
| Slack, Notion, Loom, Linear, Bear, Stripe, Things, Basecamp | Zentrix, Quorvia, Velmora, Lumexa, Synthora, Kryvo |

Agents drift to the right-hand column because invented words are always "available". Resist it: a
coinage is acceptable only when it sounds like it could already be a word and has one obvious
spelling — and it still counts as a different direction, proposed as such.

The hearing test catches most traps: c/k, ph/f, doubled or dropped letters (Flickr, Tumblr),
homophones (Knot/Not), a multi-word name heard as one word with the small word lost ("Pebble a
Day" typed as pebbleday.com — check that domain too), and a name that sounds like an established
brand in the same space. Write down what you found in `phonetics`.

Default directions are everyday positive words, plain compounds, and common words from other
languages. Anything else — playful, mythological, invented, pop-culture — when they ask, or when you
propose it as an explicit experiment.

## A round

Pick the directions yourself: deepen the ones the log says were promising, open new ones, skip
anything `BRIEF.md` or `LOG.md` rejected. Generate broadly — dozens per direction — and throw out
the weak ones yourself before checking anything; they only want to see survivors.

Check cheapest-first, so expensive checks are spent on names that deserve them:

1. **Domains, in bulk:**
   `python3 ${CLAUDE_PLUGIN_ROOT}/skills/naming-research/scripts/naming.py check docs/naming/<slug> <name>...`
   It skips anything checked in the last 14 days, so re-running is free. Add variants with
   `name=getname.com,name.app`; `--direction "…" --round N` records where the names came from.
   A name whose required TLDs are taken is usually done; the shortlist already leaves it out, so it
   needs no verdict. Only the bare name counts there.
2. **Conflicts**, for the survivors: same or similar name in the same space. How to search and how
   to grade severity: `${CLAUDE_PLUGIN_ROOT}/skills/naming-research/references/conflict-check.md`.
3. **Registrar confirmation**, for finalists only (below).

Then regenerate the shortlist (`naming.py shortlist docs/naming/<slug>`), append the round to
`LOG.md` — including your proposal for the next one, because "go with the verbs" next session only
means something if the log says what the verbs were — and report. The report is about **directions and what they taught you** — "everyday
nature words are saturated in .com; two-word compounds with a verb still have room" — followed by
the best few names with their evidence, and your proposal for the next round. Then stop and let
them decide.

## Their feedback

Record it the moment they give it, before doing anything else:

- on the name in `names.json` (`verdict`, `feedback`);
- if it generalises — "too cute", "no food words", "I like verbs" — as a standing preference in
  `BRIEF.md`, which is what makes the next round honour it without being reminded;
- as the opening of the next round's `LOG.md` entry — earlier entries stay as written.

A preference you inferred but they never stated is labelled as yours in `BRIEF.md`.

## What the domain check can and cannot say

`taken` comes from DNS or the registry and is reliable. `likely-free` means the registry has no
record — it does not mean the domain can be bought at the normal price: registries hold premium
and reserved names that look free from outside. Only a registrar settles that.

For finalists, open Porkbun's search (`https://porkbun.com/checkout/search?q=<domain>`) with
browser automation (`mcp__playwright__*`) and record `free` with the price, `premium` with the
price, or `taken`. Playwright is the host project's to provide; when it is missing, say so, offer
`claude plugin install playwright@claude-plugins-official`, and present finalists as
`likely-free — not confirmed at a registrar`.

## Searching the web

Conflict research follows the `web-search` skill (from the `web-search` plugin, which this plugin
depends on): Exa first, exact names quoted, and "I found no conflict" is a statement about your
search, not about the world — say which places you checked.

## Language

Talk in the user's language. Write the folder in English.
